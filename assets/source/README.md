# Raster sources

`glimra-poses.png` is the retained original generated raster sheet: front pose in the left square cell, rear pose in the right. Derived transparent 64×64 PNGs are produced by `scripts/export_sprites.py` using Pillow, nearest-neighbor sampling and a bottom-center contact anchor. No runtime dependency on Pillow.

Direction: original ember fox, charcoal socks, cream muzzle/chest, angular ears and a curled tail carrying a teardrop ember. A genuine rear view shows nape, rump and backs of ears. Dark sea-green outline, copper and amber clusters, no text or background. Generated using the built-in image generation tool. Source dimensions: 1774×887 RGBA. The two poses remain one source of truth; derivatives are reproducible and replaceable.
