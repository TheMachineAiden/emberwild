# Briarwick compact-world concept

Active style study: `briarwick-a-environment-concept-v2.png`, labelled STYLE
CONCEPT in the image. This generated raster combines the selected compact A
human proportions with russet roofs, warm cream plaster, teal doors/shutters,
clustered sage foliage, calm meadow grass, a pale path and a readable water bank.
The explorer, apron-wearing villager and older villager demonstrate cast contrast.

This is an early visual hypothesis, not a game screenshot, production atlas or
proof of native pixel precision. Human scale, directional frames, feet, occlusion
and actual phone readability still require a playable sample. The illustrated
layout does not replace existing map/path/collision data. The first concept is
retained separately; v2 removes an extra tree from the open central passage.

The isolated house/tree source is `assets/source/compact-briarwick-master.png`.
Its original transparent alpha is retained. No production derivatives are active
yet. The source board is `human-options-2026-11-08.png`; only column A supplies
human direction. Neither the reference board nor these images are runtime assets.

then integrate one native Briarwick scene at844×390 and667×375 using the retained
art contract. Runtime art and code remain identical to the published PR8 state at
